# Vision Care · convención de la organización

Este repositorio contiene los archivos de comunidad que GitHub aplica a todos los repositorios de la organización que no definen los suyos.

| Archivo | Contenido |
|---|---|
| `CONTRIBUTING.md` | Convención de ramas, mensajes de commit y pull requests |
| `.github/ISSUE_TEMPLATE/historia-de-usuario.yml` | Plantilla de historia de usuario |
| `.github/ISSUE_TEMPLATE/config.yml` | Selector de plantillas y enlaces de contacto |
| `.github/pull_request_template.md` | Plantilla de pull request |

La convención completa y el contexto del proyecto viven en el repositorio central [vision-care](https://github.com/vision-care-icesi/vision-care).

## Labels de la plantilla

La plantilla `historia-de-usuario.yml` asigna los labels `type/story` y `status/needs-refinement`. Para que GitHub los aplique, ambos deben existir en este repositorio y en cada repositorio donde se cree un issue con la plantilla.
